# Segurança

Nunca publique credenciais, senhas de aplicativo, tokens ou URIs privadas do banco de dados neste repositório.

Use o arquivo `.env` apenas localmente e mantenha no Git somente o `.env.example` com valores vazios ou de exemplo.

Se alguma credencial real tiver sido publicada anteriormente, revogue ou troque essa credencial no serviço correspondente.
